# kr3-corpus

子部文献プレーンテキスト・コーパス（儒家・兵家・法家・農家・醫家・天文算法・術數・藝術・譜錄・雜家・類書・小說家、867件・約575MB）

## 概要

本リポジトリは、Kanseki Repository（漢籍リポジトリ、通称Kanripo）が公開する漢籍テキストデータのうち子部（KR3）から、機械可読なプレーンテキストを抽出・整形したコーパスである。KR-Catalog の子部目録に載る888件のうち、Kanripo側にリポジトリのある867件を収録する。残る21件はリポジトリが公開されておらず、収録できない（catalog.csv 参照）。

## 出典と作成方法

- 底本データ: Kanseki Repository（https://github.com/kanripo 、1文献1リポジトリ構成）
- 採用版本: 各リポジトリの master ブランチ（全件）。採用ブランチと取得時コミットSHAは catalog.csv の witness・commit 列に全件記録
- master の底本（各本文ファイルの BASEEDITION による実測）: WYG（四庫全書文淵閣本）794件、SBCK（四部叢刊）71件、TZH 1件、CHANT 1件。文献ごとの値は catalog.csv の baseedition 列にある
- 分類・書誌典拠: kanripo/KR-Catalog の子部目録（KR/KR3a.txt〜KR3l.txt、コミット 781711923e2ce6f82f6dacfb8576cd80774b7ec0）
- 取得日: 2026-10-07

## フォルダ構成

類／文献の二層構造（例: `KR3a/KR3a0002.txt`）。1作品1ファイル（多巻本も分割せず1ファイルに収録）。分類・書誌などの意味情報はすべて catalog.csv に持たせる。

```
kr3-corpus/
├── KR3a/ 〜 KR3l/     各類（類／文献の二層）
├── catalog.csv         書誌・分類・取得情報
├── LICENSE             CC BY-SA 4.0 ライセンス全文
├── NOTICE_KANRIPO.md   底本の出典・ライセンス・加工内容の詳細
└── README.md           本ファイル
```

最も大きいファイルは `KR3k/KR3k0059.txt`（御定佩文韻府、63,395,072バイト）で、50MiBを超える。ほかのファイルはすべて50MiB未満である。

## テキスト整形方針

整形には corpus-search-toolkit の `scripts/kanripo_convert.py`（v1.3.0）を用いた。kr5-corpus・kr1-corpus・kr2-corpus と同じ規則である。

- 底本のmandoku形式（org-mode系）テキストから本文を抽出。**本文の文字そのものには改変を加えていない**（異体字の統一、Unicode正規化、外字参照の置換をしていない）
- 行頭が「#」の行は除去（冒頭のメタデータ行 #+TITLE 等のほか、本文の途中にある `#+PROPERTY:`・`# page missing` などの行を含む。書誌情報は catalog.csv へ）
- 頁の変わり目に【KR3a0002_SBCK_001-1a】形式のマーカーを保持（底本の `<pb:...>` を変換したもの）。マーカーは独立した1行で、次の1行にその頁の本文全体が入る（頁ごとに1行）
- 原本の行末記号「¶」は除去し、物理行を連結。字下げの全角空白は残る
- 画像リンク（`<md:...>`・`<img:...>`）は除去（子部の底本には該当が無かった）
- 巻ファイルを名前順に統合して1作品1ファイルとし、巻ごとに末尾の空白を除いて改行1つでつなぐ
- 文字コードはUTF-8（BOMなし）、改行はLF
- 割注は底本のとおり `(乾下/乾上)` の形で残る（丸括弧が割注、「/」が割注の中の行替え）。四庫底本の文献には「欽定四庫全書」等の巻頭表記と提要が底本通り残る

検索するときは次の点に注意されたい。

- 頁をまたぐ語は頁マーカー行で分断され、行をまたぐ語には字下げの全角空白や割注の「/」「)(」が挟まることがある
- 同じ文献の中に「教」と「敎」のような異体字が混在する（底本の字体のまま）
- 類書のうち語を見出しに立てるもの（KR3k0059 御定佩文韻府、KR3k0056 御定駢字類編、KR3k0057 御定分類字錦、KR3k0058 御定子史精華、KR3k0060 御定韻府拾遺、KR3k0030 古今合璧事類備要、KR3k0039 韻府羣玉など）では、引用文の中の見出しの語が「丨」に置き換えられている（底本の体例。例: 見出し「敎育」の下に「孟子得天下英才而丨丨之」）。こうした引用文は、見出しの語の文字列では検索に掛からない。「丨」は48文献に計3,113,367字ある
- KR3k0012 太平御覽と KR3k0013 冊府元龜は、巻1000の巻ファイルの名前が4桁（`_1000.txt`）で、巻ファイルを名前順に読むために、巻1000の本文が巻100と巻101の間に入っている（頁マーカーは【KR3k0012_SBCK_1000-1a】の形）。ファイルの末尾は巻999である
- 外字は `&KR0694;` の形の参照のまま残る。計63,720件・3,267種が699文献にある。このうち `&KR…;` の形が62,418件・2,815種、`&ZX-…;` の形が1,299件・450種（KR3k0043 稗編に822件、KR3k0006 初學記に477件）、`&CH-…;` の形が3件・2種（KR3j0192 新論）である。最も多い文献は KR3k0059 御定佩文韻府（7,412件）と KR3h0070 六藝之一錄（6,427件）である。`&KR…;` の字形は kanripo/KR-Gaiji で確認できる
- 角括弧に入った組字式（`[病-丙+(穩-禾)]` の形。その字を部品の足し引きで示したもの）が1,041件・39種、145文献にある。外字参照と同じく1字の代わりである
- 割注の中などに半角空白の並びが残る文献がある。計225,891箇所（264文献）で、うち KR3k0056 御定駢字類編に163,856箇所、KR3k0055 御定淵鑑類函に21,474箇所、KR3e0079 本草綱目に11,097箇所ある。語の途中に入ることがある
- 字の代わりに「?」（268箇所・52文献。うち KR3k0059 に110箇所）、「>」（198箇所・31文献。醫家類に多く、KR3e0067 普濟方に53箇所）、「B」（54箇所・3文献。うち KR3k0044 萬姓統譜に51箇所）が入っている箇所がある。いずれも上流のデータのままである
- 上流のデータに由来する記法が一部に残る: `<折 t="33"/>` 245箇所（KR3g0004・KR3j0024・KR3k0012・KR3k0035・KR3l0027 の5文献。うち KR3k0012 太平御覽に151箇所）、`<欠>` 2箇所（KR3f0057）、Readme の版本表の混入1箇所（KR3h0017 圖畫見聞誌。「* 版本 | SBCK|【四部叢刊】 | …」の形）。該当文献は review_flag 列に記した
- KR3f0057 佛國暦象編は、上流の本文に行頭が「%」の行が746行あり（「% BR1.1a」の形が502行、「%<pb:…>」の形が244行）、整形後の本文に「%」が746個残る。各頁の行の末尾に「% BR1.1a」の形の文字列が付くので、この文献では、頁をまたぐ語は頁マーカー行と「% BR…」で分断される。頁マーカーに【KR3f0057_TZH_004-】の形のものが1つある
- KR3j0192 新論の頁マーカーは【KR3j0192_CHANT_001-1a】の形である

## catalog.csv の列

id, subcat, subcat_name（儒家類等）, title, era（朝代）, author, date_ca（目録の DATE 欄）, extent（目録の巻数表記）, juan（本体の巻数、整数）, source（目録の SOURCE 欄）, editions（目録の版本欄。SBCKの底本注記は〔　〕内）, persons（目録の人物欄の全員。「名|朝代|職|生没」を「;」で区切る）, appendix（附録などの節。「節名[巻数]{人物}」を「 // 」で区切る）, baseedition（本文ファイルの BASEEDITION＝master の実際の底本）, han_chars（漢字数）, review_flag, status（機械生成・未検証／検証済）, path, witness（採用ブランチ）, repo_status（取得済／取得不能（リポジトリ欠落））, commit（取得時SHA）

title・era・author は目録の見出し行（「題名-朝代-著者」）を分けたものである。したがって era は見出し行の朝代であり、注釈・音義・考證などを加えた人物の朝代は persons 列にある。文字コードはBOM付きUTF-8、888行（見出し行を除く）。
